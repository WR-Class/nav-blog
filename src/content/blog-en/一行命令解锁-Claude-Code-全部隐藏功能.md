### 前言

不少开发者在使用 Claude Code 时都会有明显限制感：即便付费订阅，高规格 Opus 模型、百万级上下文窗口、多 AI 协同等功能依旧锁死；咨询安全渗透、漏洞研究相关内容会被直接拦截；执行删除文件等高危操作时会反复弹出确认弹窗；同时官方会通过远程开关管控各类实验性功能。
这些约束并非技术能力不足，而是 Anthropic 官方主动关闭了客户端内部能力。开源工具 ClawGod 通过本地补丁二开方式，仅需一行脚本即可解除全部限制，30 秒完成部署，支持一键卸载还原官方原版客户端。

### 一、ClawGod 工具核心定位

ClawGod 是一款面向 Claude Code 的本地开源运行时补丁，遵循 GPL-3.0 开源协议，仅对本地客户端做行为修改，不篡改账号认证逻辑、不绕过官方 API 限流，所有网络请求仍走 Anthropic 官方通道。
部署后可实现：删除内置安全过滤指令、解锁全系列模型与超大上下文、启用多智能体团队协作、自定义 API 中转地址、本地接管全部功能开关、关闭后台遥测采集，安装后客户端标识变为绿色，直观区分原版橙色界面。

### 二、六大核心解锁能力详解

###### 1. 全模型 + 百万上下文无门槛解锁

原版 Claude Code 会根据订阅等级划分模型使用权限，ClawGod 修改客户端身份标识，伪装为 Anthropic 内部员工，无视订阅等级开放全部模型：
表格

| 订阅档位  | 官方原版可用能力     | ClawGod 解锁后完整权限              |
| ----- | ------------ | ---------------------------- |
| 免费用户  | 基础轻量化模型      | Opus 全系列模型 + 100 万 token 上下文 |
| 专业订阅  | 中端十四行诗模型     | Opus 4.6 + 1M 超大上下文窗口        |
| 最高付费档 | 高阶模型（无百万上下文） | Opus 4.6 + 完整百万级长文本支持        |

工具原理：将用户身份字段从external外部用户修改为ant内部员工，绕过服务端订阅校验逻辑。

###### 2. 内部用户模式，本地接管远程功能开关

Anthropic 依靠 GrowthBook 远程系统统一管控全球用户的功能灰度，大量实验性功能默认对外隐藏。
ClawGod 注入环境变量CLAUDE_INTERNAL_FC_OVERRIDES，支持通过本地 JSON 配置强制开启 / 关闭任意隐藏功能，示例配置模板：

```json
{
  "tengu_harbor": true,
  "tengu_session_memory": true,
  "tengu_amber_flint": true,
  "tengu_auto_background_agents": true
}
```

所有功能开关权限完全交由本地用户自主控制。

###### 3. Agent Teams 多 AI 协作客户端解禁

Agent Teams 是 Claude Code 内置的多智能体协同功能，原版需要手动配置特殊环境变量才能开启，ClawGod 直接移除客户端内的启用条件判断，默认全量激活：
Agent1：负责整体项目架构拆解与需求分析
Agent2：自动化编写单元测试、集成测试用例
Agent3：完成代码审计、漏洞扫描与逻辑复审
多个 AI Agent 并行工作，互不阻塞，大幅提升大型项目开发、代码审计效率。

###### 4. 安全研究限制全部移除（渗透 / 漏洞场景刚需）

官方内置三条硬性拦截指令，是安全研究员、CTF 选手、渗透工程师的核心痛点，ClawGod 会完整删除三条约束规则：
CYBER_RISK_INSTRUCTION：移除渗透测试、漏洞利用、C2 远控框架相关问答拦截，安全类提问不再拒绝回复；
URL 生成限制：取消禁止生成、批量枚举、猜测目标 URL 的约束；
操作审慎指令：删除文件批量删除、覆盖、系统修改等高风险操作的强制确认弹窗，自动化脚本执行无需人工反复确认。

###### 5. 自定义 API 代理 / 中转，灵活切换模型

支持自定义 API 密钥、后端接口地址与默认模型，适配第三方中转服务、自建代理节点，配置模板：

```json
{
  "apiKey": "你的API密钥",
  "baseURL": "https://api.anthropic.com",
  "model": "claude-opus-4-6"
}
```

###### 6. 附加优化项

客户端状态标识：橙色 = 原版受限模式，绿色 = 补丁完全生效；
自动关闭后台遥测数据采集，停止使用行为上报；
内置原版客户端备份，卸载时一键恢复无残留；
适配小版本迭代，通过偏移量补偿兼容官方更新。

### 三、全平台一键安装教程

###### 前置依赖

本地预装 Node.js 18 及以上版本、npm 包管理器，拥有可正常登录的 Claude Code 有效账号。
macOS / Linux 安装命令
bash
运行

```bash
curl -fsSL https://github.com/0Chencc/clawgod/releases/latest/download/install.sh | bash
```

Windows PowerShell 安装命令

```powershell
irm https://github.com/0Chencc/clawgod/releases/latest/download/install.ps1 | iex
```

安装完成后系统生成两条命令：
claude：打补丁后的增强版客户端
claude.orig：自动备份的官方原版程序

### 四、卸载还原官方原版

无需重装客户端，单行命令即可彻底移除补丁、恢复初始状态：
macOS / Linux
bash
运行

```bash
claude --uninstall
```

Windows

```powershell
claude --uninstall
```

卸载流程无残留文件，完全还原未修改前的官方程序。

### 五、常见疑问解答

##### Q1：使用 ClawGod 是否属于破解工具，存在账号封禁风险？

A：工具仅修改本地客户端运行逻辑，不篡改账号鉴权流程、不绕开服务端 API 限流，网络请求全程遵循官方接口规则，无直接破解认证行为；但修改客户端行为可能违反 Anthropic 用户服务协议，存在潜在账号风控风险，建议仅用于本地技术研究测试。

##### Q2：Claude Code 官方版本更新后补丁失效怎么办？

A：工具内置正则偏移补偿机制，小版本迭代基本自动兼容；若大版本更新导致补丁失效，等待项目作者同步更新安装脚本即可。


##### Q3：工具是否开源、代码是否可审计？

A：项目完整开源托管于 GitHub，遵循 GPL-3.0 开源协议，所有补丁修改代码均可逐行查阅审计，无闭源黑盒逻辑。
